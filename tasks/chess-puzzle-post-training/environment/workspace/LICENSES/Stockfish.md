# Stockfish notice

The CPU workspace installs Debian Bookworm's unmodified `stockfish` package
(version 15.1-4 at release validation). Stockfish is licensed under the GNU General
Public License version 3. The installed notice is `/usr/share/doc/stockfish/copyright`;
the complete license is `/usr/share/common-licenses/GPL-3`.

Corresponding source is available from [Debian's Stockfish 15.1-4 source package](https://sources.debian.org/src/stockfish/15.1-4/)
and the [upstream Stockfish repository](https://github.com/official-stockfish/Stockfish/tree/sf_15.1).
The Debian package supplies the engine binary in the workspace image; no engine binary
is checked into this repository.
